Полный список голосовых команд (произносить после wake-word «Шурочка, …»):

  GLOBAL — управление ассистентом

  - Stop / выключить дежурный режим:
    - «остановись пожалуйста»
    - «закончи работу»
    - «отключись пока»

  INSTANT — управление плеером/системой

  - Пауза: «поставь паузу» / «поставь на паузу» / «сделай паузу»
  - Продолжить: «сними паузу» / «продолжи воспроизведение» / «продолжай играть»
  - Громче: «сделай громче» / «прибавь громкость» / «увеличь громкость»
  - Тише: «сделай тише» / «убавь громкость» / «уменьши громкость»
  - Mute: «выключи звук» / «убери звук» / «заглуши плеер» / «без звука»
  - Unmute: «включи звук» / «верни звук» / «со звуком»
  - Перемотка вперёд: «перемотай вперёд» / «промотай вперёд» / «следующий трек»
  - Перемотка назад: «перемотай назад» / «промотай назад» / «предыдущий трек»
  - Скриншот: «сделай скриншот» / «сними скриншот» / «сохрани скриншот» / «сохранить скриншот» / «сними экран»

  CONTENT — заметки и LLM

  - Заметка (после фразы говорите текст заметки):
  «запиши заметку» / «напиши заметку» / «сохрани заметку» / «сделай заметку» / «добавь заметку» / «новая заметка»
  - Вопрос к LLM (после фразы — сам вопрос):
  «ответь на вопрос» / «нужна помощь» / «нужна консультация» / «дай консультацию» / «подскажи пожалуйста» / «объясни мне»

  Не голосом (UI/трей/hotkey для M8)

  - Esc в окне — отмена текущего хода (Cancel)
  - Ctrl+Alt+S глобально — вернуть дежурный режим после StopCommand
  - Трей → «Включить ассистента» — то же, что hotkey
  - Трей → «Открыть папку сессии» / «Перезагрузить конфиг» (заглушка) / «Выход»

  Все синонимы строго ≥2 слов — однословные не сработают (защита от шума Whisper'а).
