# Шурочка — локальный голосовой ассистент (Voice AI Assistant v2)

Полностью оффлайн голосовой ассистент для Windows. Слушает кодовое слово
**«Шурочка»**, распознаёт команды/вопросы, управляет системой и отвечает
синтезированной речью. Ни звук, ни текст не уходят наружу — все модели
(STT, LLM, TTS) крутятся локально на машине пользователя.

---

## Суть и предназначение

Шурочка закрывает три задачи сразу:

1. **Голосовое управление Windows без облака** — пауза/воспроизведение в плеерах,
   громкость, mute сторонних аудио-сессий (кроме голоса ассистента), скриншоты,
   диктовка заметок.
2. **Локальный Q&A через LLM** — свободные вопросы к домашней LLM-модели
   (Ollama или LM Studio), но строго по явному триггеру («ответь на вопрос…»,
   «подскажи…»). Случайный шум Whisper'а в LLM не уходит.
3. **Дежурный режим по wake-word** — ассистент «дремлет» на микрофоне и
   активируется коротким «Шурочка, …».

Основная мотивация — приватность и автономность. Проект собран из
взаимозаменяемых провайдеров (STT / LLM / TTS), каждый из которых можно
переключить одной строкой в `config.py`.

---

## Функционал и возможности

- **Пайплайн:** `AudioStream → VAD → STT (Whisper) → CommandRouter → (Command | LLM) → TTS → AudioPlayer`.
- **Wake-word** «Шурочка» + алиас «Шура»; настраиваемые таймауты и сигнальные бипы.
- **Командная система M1–M8** — детерминированный роутер с нормализацией и матчингом по синонимам (exact или prefix).
- **Контентные действия** — заметки, скриншоты, Q&A — собираются в папку текущей сессии `logs/sessions/YYYY-MM-DD_HH-MM/`.
- **Per-session mute через pycaw** — при команде «выключи звук» Windows-сессии глушатся, кроме голоса самой Шурочки.
- **Tkinter UI** с уровнемером RMS, маркерами шума/порога, health-pills Whisper/LLM/TTS и просмотром лога.
- **Overlay** — полупрозрачный click-through статус-виджет поверх всех окон.
- **System tray** (pystray) + глобальная hotkey **Ctrl+Alt+S** для возврата в дежурный режим.
- **IPC-сервер** (TCP line-JSON, `127.0.0.1:9999`) — другие процессы могут вызывать методы `health_check`, `generate_only`, `transcribe_and_respond`, `recalibrate`.
- **GPU VRAM swap** — если TTS=XTTS и крутится на CUDA, Whisper автоматически выгружается на время синтеза и перезагружается после (одновременно они в 8–12 ГБ VRAM не помещаются).
- **Взаимозаменяемые провайдеры** — Whisper / (Ollama|LM Studio) / (Silero|XTTS) за общими ABC из `core/base.py`.
- **Чистка reasoning-tokens** — `<think>…</think>`, harmony-каналы, freeform «Thinking Process:» снимаются до TTS, чтобы Silero не проговаривал внутренние рассуждения модели.
- **Защита от ложных срабатываний** — все синонимы команд ≥2 слов, однословные отфильтровываются `CommandRegistry`.

## Список готовых команд

> Произносить после активации wake-word: *«Шурочка, <команда>»*. Все синонимы строго ≥2 слов.

### GLOBAL — управление ассистентом
| Действие | Синонимы |
|---|---|
| Выключить дежурный режим | «остановись пожалуйста», «закончи работу», «отключись пока» |

### INSTANT — плеер и система
| Действие | Синонимы |
|---|---|
| Пауза | «поставь паузу», «поставь на паузу», «сделай паузу» |
| Продолжить | «сними паузу», «продолжи воспроизведение», «продолжай играть» |
| Громче | «сделай громче», «прибавь громкость», «увеличь громкость» |
| Тише | «сделай тише», «убавь громкость», «уменьши громкость» |
| Mute (per-session) | «выключи звук», «убери звук», «заглуши плеер», «без звука» |
| Unmute | «включи звук», «верни звук», «со звуком» |
| Следующий трек | «перемотай вперёд», «промотай вперёд», «следующий трек» |
| Предыдущий трек | «перемотай назад», «промотай назад», «предыдущий трек» |
| Скриншот | «сделай скриншот», «сними скриншот», «сохрани скриншот», «сохранить скриншот», «сними экран» |

### CONTENT — заметки и Q&A
| Действие | Синонимы (дальше произносится само содержание) |
|---|---|
| Заметка | «запиши заметку», «напиши заметку», «сохрани заметку», «сделай заметку», «добавь заметку», «новая заметка» |
| Вопрос к LLM | «ответь на вопрос», «нужна помощь», «нужна консультация», «дай консультацию», «подскажи пожалуйста», «объясни мне» |

### Не голосом (UI / трей / hotkey)
- **Esc** в окне приложения — отмена текущего хода (Cancel).
- **Ctrl+Alt+S** глобально — вернуть дежурный режим после `StopCommand`.
- **Трей** → «Включить ассистента» / «Открыть папку сессии» / «Выход».

## Используемые модели

### STT — распознавание речи
- **OpenAI Whisper** (`openai-whisper==20240930`).
- По умолчанию: `WHISPER_MODEL_SIZE = "large-v3-turbo"` на `cuda`, язык `russian`.
- Запасная модель: `large-v3` (файлы весов — `models/large-v3*.pt`).
- `large-v3-turbo` быстрее large-v3 примерно в 2 раза при сравнимом WER на разговорной речи.

### LLM — ответы на вопросы
- Два взаимозаменяемых бэкенда (переключаются через `LLM_PROVIDER`):
  - **LM Studio** (OpenAI-compatible REST, `http://localhost:1234/v1`) — по умолчанию.
  - **Ollama** (`http://localhost:11434`).
- Текущая используемая модель: `gemma-4-coder` (имя в обоих бэкендах, меняется в `OLLAMA_MODEL` / `LMSTUDIO_MODEL`).
- Thinking-модели (со `<think>…</think>`, harmony-каналами, «Thinking Process:») авто-детектируются и получают 3× токенов на ответ; reasoning-теги снимаются до TTS.
- Системный промпт — русскоязычный, plain text (без markdown / emoji / латиницы), чтобы не ломать Silero.

### TTS — синтез речи
- **Silero v5_4_ru** (по умолчанию) — нативная русская модель, CPU, ~140 МБ, real-time.
  - Спикер `xenia`, sample rate 48 kHz, автоударения + «ё», вопросительная интонация (intensity=3).
  - Освобождает GPU под Whisper → GPU-swap не нужен.
- **Coqui XTTS-v2** (альтернатива) — мультиязычный, GPU, поддержка voice-cloning.
  - Встроенные спикеры (`Claribel Dervla` по умолчанию) либо reference-WAV из `tests/fixtures/sample.wav`.
  - На CUDA конфликтует с Whisper за VRAM → включается GPU-swap.

### Wake-word
MVP-реализация поверх того же Whisper: короткие окна по 4 секунды сканируются
в цикле, exact-match по токенам `шурочка` / `шура`. Без Porcupine и без сторонних engine'ов.

## Блок-схема работы

```
   ┌──────────────────┐
   │  Микрофон Windows │ (системный дефолт, выбирается пользователем в Параметрах)
   └────────┬──────────┘
            │ 16-bit PCM, 16 kHz
            ▼
   ┌──────────────────┐
   │  AudioStream      │ daemon-поток, per-chunk RMS, noise_floor, chunk_queue
   └────────┬──────────┘
            │
            ▼
   ┌──────────────────────────┐        дежурный режим
   │ WakeWordListener          │──────────────────────────┐
   │ (окна 4с → Whisper →      │                          │
   │  match "шурочка"/"шура")  │   нет wake-word → сброс  │
   └────────┬──────────────────┘                          │
            │ есть wake-word → beep ON                    │
            ▼                                              │
   ┌──────────────────┐                                    │
   │ VAD              │ calibrate() / record_until_silence()
   │ (порог = шум×1.8)│                                    │
   └────────┬──────────┘                                    │
            │ WAV с фразой пользователя                    │
            ▼                                              │
   ┌──────────────────┐                                    │
   │ Whisper STT      │ large-v3-turbo, cuda, ru          │
   └────────┬──────────┘                                    │
            │ распознанный текст                            │
            ▼                                              │
   ┌─────────────────────────────────┐                     │
   │ CommandRouter                    │                    │
   │ normalize → match по синонимам   │                    │
   └────────┬─────────────────────────┘                    │
            │                                               │
    ┌───────┴─────────────┬─────────────────┐              │
    ▼                     ▼                 ▼              │
  INSTANT            DICTATE/CONTENT        LLM            │
  (media keys,       (note → SessionMgr,    (LM Studio /   │
   pycaw mute,        screenshot → PNG)      Ollama)       │
   screenshot)                                             │
    │                     │                 │              │
    └──────────┬──────────┴─────────────────┘              │
               │ ack-фраза или ответ                        │
               ▼                                            │
         ┌──────────────┐                                   │
         │ TTS          │ Silero (CPU) | XTTS (GPU-swap)    │
         └──────┬────────┘                                   │
                ▼                                            │
         ┌──────────────┐                                   │
         │ AudioPlayer  │ sounddevice, блокирующее воспр.   │
         └──────┬────────┘                                   │
                │ beep OFF → возврат в дежурный ────────────┘
                ▼
           Динамики (Windows default output)
```

Параллельно всему пайплайну:
- **Tkinter UI** (main thread) — кнопки, уровнемер, health-pills.
- **IPC-сервер** на `127.0.0.1:9999` (daemon thread) — `health_check`, `generate_only`, `transcribe_and_respond`, `recalibrate`.
- **Overlay** + **tray** + **глобальная hotkey** `Ctrl+Alt+S` — возврат в дежурный режим.
- Единый `threading.Lock` на `VoicePipeline` сериализует доступ к микрофону и моделям из REPL / IPC / wake-word listener.

## Порядок запуска и первичной настройки

### 1. Подготовка окружения
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Отдельно установить PyTorch с поддержкой CUDA 12.x (версия подбирается по GPU/драйверам) — см. `pytorch.org`.

### 2. Веса Whisper
Файлы `models/large-v3-turbo.pt` и `models/large-v3.pt` уже лежат в проекте.
Если чего-то нет — `openai-whisper` докачает автоматически при первом `load_model()`.

### 3. LLM-бекенд
Запустить **один** из:
- **LM Studio** — загрузить модель (по умолчанию ищется `gemma-4-coder`), стартануть локальный сервер на `:1234`.
- **Ollama** — `ollama serve`, затем `ollama pull gemma-4-coder` (или любая другая, поправить `OLLAMA_MODEL` в `config.py`).

Переключение между ними — строка `LLM_PROVIDER = "lmstudio"` / `"ollama"` в `config.py`.

### 4. Выбор аудио-устройств
Приложение **не пинит** устройства — оно берёт Windows-дефолты.
- `Параметры → Система → Звук → Ввод / Вывод` — выбрать нужные.
- `python -m utils.audio_devices` — напечатает список всех устройств и отметит текущие дефолты.

### 5. Запуск
```bash
# Tkinter UI с диагностикой (основной режим)
python main.py

# Консольный REPL + IPC-сервер
python main.py --mode console

# Headless IPC-сервер
python main.py --mode ipc

# Консоль без IPC
python main.py --mode console --no-ipc
```

При старте `bootstrap()` печатает текущие Windows-дефолты входа/выхода —
**убедиться, что они те, что ожидаются**.

### 6. Калибровка VAD
- В UI — кнопка **«🔄 Перекалибровать»**. Во время 2-секундного окна **молчать**, чтобы
  замерился реальный уровень фонового шума.
- Порог детекции речи = `max_rms × 1.8` (но не ниже `MIN_ENERGY_THRESHOLD = 150`).
- В консольном режиме калибровка выполняется автоматически при старте (также 2 секунды молчания).
- В дальнейшем порог сам адаптируется к медленно меняющемуся шуму (`DYNAMIC_ENERGY_DAMPING = 0.15`).
- На уровнемере в UI: синий маркер = noise_floor, красный = threshold. Если речь не триггерит — калибровать заново.

### 7. Проверка wake-word
- Включить дежурный режим (кнопка **«🛌 Дежурный»** или глобальная **Ctrl+Alt+S**).
- Сказать **«Шурочка»** — должен проиграться активационный beep (880 Гц).
- Сразу после beep — произнести команду или запрос.
- По завершении (ответ/таймаут 8 с) играет beep возврата (440 Гц) — ассистент снова дремлет.

### 8. Первичная генерация ack-фраз (опционально)
Файлы в `assets/ack/*.wav` уже пререндерены. Если нужно пересобрать (например, после смены голоса Silero):
```bash
# удалить существующие
rm -rf assets/ack/
python -m utils.generate_ack_phrases
```

### 9. Запуск тестов
```bash
pytest
pytest tests/test_wake_word.py
```

## На чём тестировался проект

### ОС и железо
- Windows 10 Pro 10.0.19045.
- Python 3.10.
- NVIDIA GPU с CUDA 12.x.

### LLM-бекенды
- **LM Studio** — OpenAI-совместимый REST на `:1234`. Основной бэкенд по умолчанию.
- **Ollama** — `:11434`. Альтернатива.
- Тестовая модель: `gemma-4-coder` (а также thinking-модели с `<think>` / harmony-теги — чистятся автоматически).

### Плееры и медиа-источники (команды паузы / громкости / перемотки)
Команды работают через Win32 media-keys (`VK_MEDIA_PLAY_PAUSE`, `VK_MEDIA_NEXT/PREV_TRACK`,
`VK_VOLUME_UP/DOWN`), поэтому поддерживается любой плеер, реагирующий на системные
мультимедиа-клавиши Windows:

- **Яндекс.Браузер** — YouTube, Twitch, любая вкладка с аудио/видео.
- **VLC**, **MPC-HC** — десктопные плееры.
- **Spotify** — десктоп-приложение.
- Любой Chromium-based браузер с включённым Media Session API.

### Mute (pycaw per-session)
Отдельные аудио-сессии Windows (каждое приложение — своя сессия) —
глушатся/разглушаются через pycaw, **кроме** собственной сессии Шурочки,
чтобы голос ассистента был слышен даже при «выключи звук».

### Скриншоты
Через `mss` — основной монитор по умолчанию; для многомониторной конфигурации
задаётся индекс монитора.

### IPC
Проверено in-process (сервер+клиент в одном процессе, `check_stage_6.py`) и на
loopback-соединении через `VoiceAIClient`.

### Принятые этапы (ручная валидация через `check_stage_*.py`)
Этапы **5** (pipeline), **6** (IPC), **7** (Tkinter UI), **8** (wake-word) и миграционные
**M4** (pause/mute/volume), **M6** (stop/seek/cancel), **M8** (overlay/tray/hotkey)
прошли приёмку по чек-листам и скрипты удалены из актуального цикла (оставлены
в проекте для ретро-верификации).
