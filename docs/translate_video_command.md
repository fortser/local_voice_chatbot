# Команда «переведи видео» — обслуживание

Команда `TranslateVideoCommand` (`commands/translate_video_command.py`) кликает по кнопке «Перевести и озвучить» в Яндекс.Браузере через поиск шаблона на экране (`pyautogui.locateOnScreen`).

Шаблон иконки: `assets/yandex_translate_icon.png`.

## Когда команда перестаёт работать

В логе (`logs/voice_ai.log`) появляется:

```
TranslateVideoCommand: иконка не найдена (confidence>=0.80)
```

И/или ack «не получилось включить перевод» проигрывается раз за разом, даже когда YouTube открыт в фуллскрине и панель Яндекса видна.

Две основные причины:

1. **Яндекс перерисовал иконку** (новый стиль, цвет, шрифт текста «Перевести и озвучить»).
2. **У тебя сменилось разрешение / DPI-масштаб** — иконка стала рендериться в других пикселях, шаблон не совпадает по размеру.

## Что делать — пошагово

### Шаг 1. Сделать новый скриншот иконки

1. Открыть YouTube в **полноэкранном** режиме (важно: фон в фуллскрине отличается от оконного).
2. Подождать, пока появится верхняя панель Яндекса.
3. `Win + Shift + S` → выделить **только саму кнопку** «🅈 🇦 Перевести и озвучить ⌄» — без правой группы кнопок (чат / вопрос / субтитры / «…»).
4. Сохранить как PNG (без потерь) поверх старого файла:

   ```
   assets/yandex_translate_icon.png
   ```

   Имя должно совпасть — больше нигде путь не правится.

### Шаг 2. Проверить

```bash
python main.py --ui pyside6
```

Открыть YouTube в фуллскрине, сказать «Шурочка, переведи видео». Должна сработать с первой-второй попытки.

### Шаг 3. Если всё равно не находит — снизить порог совпадения

В `commands/translate_video_command.py`:

```python
_MATCH_CONFIDENCE = 0.8   # снизить до 0.7 или 0.65
```

- `0.8` — строго (минимум ложных срабатываний)
- `0.7` — компромисс
- `0.65` и ниже — рискованно, может кликать не туда

### Шаг 4. Если иконка точно есть, а ищет долго

Увеличить число retry'ев — в `commands/translate_video_command.py` они считаются от конфига `WAKE_HINT_*`. Если оверлей подсказок Шурочки висит дольше расчётного, в самом коде менять не надо — увеличь `WAKE_HINT_HOLD_MS` в `settings.toml`, и retry-бюджет подстроится автоматически.

Если хочешь форсировать вручную — поправь нижнюю границу в той же функции:

```python
_LOCATE_RETRIES = max(
    4,  # ← поднять, например, до 8
    int(_OVERLAY_LIFETIME_SEC * 1.5 / _LOCATE_RETRY_DELAY_SEC) + 1,
)
```

## Что НЕ нужно делать

- **Не делай скриншот в оконном режиме YouTube** — фон под иконкой другой, поиск в фуллскрине будет промахиваться.
- **Не захватывай в шаблон область шире самой кнопки** — чем больше шаблон, тем больше пикселей должны совпасть, тем выше шанс промаха при малейшем различии рендера.
- **Не используй JPEG** — артефакты сжатия ломают пиксельное сопоставление. Только PNG.
- **Не добавляй прозрачность к шаблону** — `pyautogui` ищет по непрозрачным пикселям, а альфа-канал даст непредсказуемый результат.

## Диагностика

В `commands/translate_video_command.py` уже есть логирование:

```
INFO  TranslateVideoCommand: иконка найдена в (X,Y), кликаю
INFO  TranslateVideoCommand: иконка найдена с N-й попытки
INFO  TranslateVideoCommand: иконка не найдена (confidence>=0.80)
```

Если иконка регулярно находится со 2-3 попытки, а не с первой — это нормально, оверлей подсказок Шурочки в это время отыгрывает fade-out. Если со всех попыток — дело в шаблоне или DPI.

Чтобы быстро проверить, видит ли `pyautogui` иконку **вне** контекста Шурочки:

```bash
python -c "import pyautogui; print(pyautogui.locateOnScreen('assets/yandex_translate_icon.png', confidence=0.8))"
```

(Запускать при открытом фуллскрин-YouTube с видимой панелью Яндекса.)

- Возвращает `Box(...)` → шаблон ок, проблема в логике/таймингах команды.
- Возвращает `None` → шаблон не подходит, переснять (Шаг 1) или снизить confidence (Шаг 3).

## Если Яндекс убрал кнопку совсем

Тогда команда нужна другая (хоткей через расширение браузера, прямой API перевода и т.п.). Текущую можно удалить:

1. Удалить `commands/translate_video_command.py`.
2. Убрать импорт и регистрацию в `commands/registry.py`.
3. Убрать запись `"translate_video"` в `utils/generate_ack_phrases.py`.
4. Удалить `assets/yandex_translate_icon.png` и оба ack-WAV в `assets/ack/translate_video_*.wav`.
5. Откатить `pyautogui` / `opencv-python` в `requirements.txt`, если больше нигде не используются.
