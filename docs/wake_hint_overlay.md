# Полноэкранная шпаргалка команд при пробуждении

## 1. Что это такое

При произнесении wake-word'а («Шурочка») поверх всех окон появляется полупрозрачный
список голосовых команд крупным жирным текстом. Оверлей удерживается заданное время
(`hold_ms`), затем плавно растворяется. Цель — напомнить, что именно сейчас можно
сказать, не переключаясь на справку.

Оверлей занимает весь экран, но **не блокирует мышь** и **не перехватывает фокус** —
ты продолжаешь работать с тем, что под ним. Один экземпляр виджета переиспользуется
между пробуждениями: мерцания нет.


## 2. Где правится

| Что            | Файл                        | Отвечает за…                              |
|----------------|-----------------------------|-------------------------------------------|
| Внешний вид    | `settings.toml`             | цвет, шрифт, таймауты, монитор, прозрачность |
| Содержимое     | `config/wake_hints.json`    | какие команды показываются и в каком порядке |

**Мастер-выключатель** — параметр `enabled` в секции `[ui.wake_hint]` в `settings.toml`.
При `enabled = false` оверлей не создаётся вообще.


## 3. Полная таблица параметров `[ui.wake_hint]`

| Параметр            | Тип    | Дефолт          | Описание                                                                 | Диапазон / варианты           |
|---------------------|--------|-----------------|--------------------------------------------------------------------------|-------------------------------|
| `enabled`           | bool   | `true`          | Включить/отключить оверлей целиком                                       | `true` / `false`              |
| `trigger_state`     | string | `"wake_active"` | State pipeline, при котором показывается оверлей                         | `"wake_active"` / `"wake_heard"` |
| `hold_ms`           | int    | `1500`          | Сколько миллисекунд висеть после завершения fade-in                      | 500–5000                      |
| `fade_in_ms`        | int    | `150`           | Длительность появления (мс)                                              | 0–500                         |
| `fade_out_ms`       | int    | `250`           | Длительность растворения (мс)                                            | 0–800                         |
| `opacity`           | float  | `0.55`          | Максимальная прозрачность окна (0.0 — невидим, 1.0 — непрозрачен)       | 0.1–1.0                       |
| `font_pt`           | int    | `32`            | Размер шрифта, пункты                                                    | 16–320                        |
| `max_items`         | int    | `10`            | Максимальное число строк в списке                                        | 1–30                          |
| `monitor`           | string | `"cursor"`      | На каком мониторе показывать: `cursor` — тот, где курсор; `primary` — основной | `"cursor"` / `"primary"`  |
| `vertical_align`    | string | `"center"`      | Вертикальное выравнивание текста внутри экрана                           | `"center"` / `"top"` / `"bottom"` |
| `text_color`        | string | `"#1a1a1a"`     | Цвет букв (CSS hex `#RRGGBB`)                                            | любой hex                     |
| `shadow_enabled`    | bool   | `true`          | Включить halo вокруг букв (улучшает читаемость на любом фоне)           | `true` / `false`              |
| `shadow_color`      | string | `"#ffffff"`     | Цвет halo — обычно противоположный `text_color`                         | любой hex                     |
| `shadow_blur`       | int    | `16`            | Радиус размытия halo, пикселей                                           | 4–64                          |
| `backdrop_enabled`  | bool   | `true`          | Показывать подложку-карточку за текстом                                  | `true` / `false`              |
| `backdrop_color`    | string | `"#fdf6e3"`     | Цвет подложки (CSS hex). Игнорируется при `backdrop_enabled = false`    | любой hex                     |

> **Примечание про `monitor = "active_window"`**: значение технически принимается,
> но ведёт себя так же, как `"primary"` — определение окна переднего плана через
> Qt не реализовано. Используй `"cursor"` для мультимониторных сетапов.


## 4. Готовые пресеты

### 4.1 По умолчанию

```toml
[ui.wake_hint]
enabled = true
trigger_state = "wake_active"
hold_ms = 1500
fade_in_ms = 150
fade_out_ms = 250
opacity = 0.55
font_pt = 32
max_items = 10
monitor = "cursor"
vertical_align = "center"
text_color = "#1a1a1a"
shadow_enabled = true
shadow_color = "#ffffff"
shadow_blur = 16
backdrop_enabled = true
backdrop_color = "#fdf6e3"
```

### 4.2 Крупный для FullHD — тёмно-красный на песочном

Увеличенный шрифт, тёмный текст, тёплая подложка. Хорошо читается при дневном свете.

```toml
[ui.wake_hint]
enabled = true
trigger_state = "wake_active"
hold_ms = 2000         # чуть дольше — успеть прочитать крупный список
fade_in_ms = 150
fade_out_ms = 300
opacity = 0.75         # плотнее, потому что фон большой
font_pt = 40
max_items = 8          # крупный шрифт — меньше строк влезает
monitor = "cursor"
vertical_align = "center"
text_color = "#5a0000"   # тёмно-бордовый
shadow_enabled = true
shadow_color = "#fdf6e3" # светлый halo в тон подложке — мягкое свечение
shadow_blur = 12
backdrop_enabled = true
backdrop_color = "#fdf6e3" # солнечный песочный
```

### 4.3 Минималистичный — без подложки

Текст прямо поверх рабочего стола. Подходит, если фон рабочего стола тёмный
или пёстрый: тёмные буквы + белый halo дают читаемость на любом содержимом.

```toml
[ui.wake_hint]
enabled = true
trigger_state = "wake_active"
hold_ms = 1500
fade_in_ms = 120
fade_out_ms = 200
opacity = 0.90         # без подложки нужна почти полная непрозрачность
font_pt = 36
max_items = 10
monitor = "cursor"
vertical_align = "center"
text_color = "#1a1a1a"   # тёмный текст
shadow_enabled = true
shadow_color = "#ffffff" # белый halo — проявляет тёмные буквы на любом фоне
shadow_blur = 20         # шире halo → лучше контраст
backdrop_enabled = false # нет подложки, буквы прямо поверх рабочего стола
backdrop_color = "#fdf6e3"  # игнорируется при backdrop_enabled = false
```

### 4.4 Тёмная тема

Светлые буквы на тёмной карточке. Подходит для ночного режима или тёмных тем ОС.

```toml
[ui.wake_hint]
enabled = true
trigger_state = "wake_active"
hold_ms = 1800
fade_in_ms = 150
fade_out_ms = 300
opacity = 0.80
font_pt = 34
max_items = 10
monitor = "cursor"
vertical_align = "center"
text_color = "#e8e0d0"   # кремово-белый
shadow_enabled = true
shadow_color = "#000000" # тёмный halo — контраст на тёмном фоне
shadow_blur = 14
backdrop_enabled = true
backdrop_color = "#1c1c1c" # почти чёрный
```


## 5. Список команд (`config/wake_hints.json`)

### Быстрый старт

Скопируй шаблон и открой в любом текстовом редакторе:

```
copy config\wake_hints.example.json config\wake_hints.json
```

### Формат файла

```json
{
  "version": 1,
  "items": [
    {"command": "note",       "label": "запиши заметку",   "show": true,  "order": 1},
    {"command": "screenshot", "label": "сделай скриншот",  "show": true,  "order": 2},
    {"command": "question",   "label": "ответь на вопрос", "show": true,  "order": 3},
    {"command": "pause",      "label": "пауза",            "show": false}
  ]
}
```

### Поля элемента

| Поле      | Тип    | Обязательно | Описание                                                                 |
|-----------|--------|-------------|--------------------------------------------------------------------------|
| `command` | string | да          | Стабильный внутренний идентификатор команды (`BaseCommand.name`). Список доступных — запусти приложение и посмотри лог: команды без записи в JSON будут перечислены как «добавлены авто-дефолтами». |
| `label`   | string | да          | Текст, который отображается на экране. Можно написать более понятную фразу, чем дефолтный синоним. |
| `show`    | bool   | нет (default `true`) | `false` — строка скрыта, но запись остаётся в файле. Удобнее, чем удалять совсем. |
| `order`   | int    | нет         | Порядок сортировки: меньше — выше. Команды без `order` идут в конце, после всех явно упорядоченных. |

### Правила слияния с реестром

- Команды из JSON, которых **нет в реестре** (команда удалена или переименована), молча пропускаются с предупреждением в лог. Файл при этом не ломается.
- Команды из реестра, которых **нет в JSON**, **добавляются автоматически** в конец списка с дефолтным синонимом. Новые фичи не теряются.
- При **битом JSON** (синтаксическая ошибка, нет поля `items`) — полный fallback к авто-генерации из реестра. Предупреждение в лог.
- `max_items` обрезает итоговый список после сортировки. Если часть команд скрыта через `show: false`, обрезка считается от видимых.


## 6. Триггер показа и поведение

- **Показывается** при переходе pipeline в state `wake_active` (по умолчанию). Это moment, когда Шурочка уже «проснулась» и ждёт следующую фразу — у тебя есть несколько секунд прочитать список.
- **Почему `wake_active`, а не `wake_heard`**: state `wake_heard` — переходный, он живёт доли секунды (момент детекции слова). Оверлей не успевает отрисоваться до следующего state. `wake_active` — устойчивое состояние ожидания, именно здесь шпаргалка нужна.
- **Скрывается** при любом переходе дальше по конвейеру: `processing`, `speaking`, `idle` и другие — оверлей немедленно начинает fade-out, чтобы не перекрывать ответ ассистента.
- **Таймаут**: если ни одного перехода не произошло (пользователь молчит), оверлей сам исчезает через `fade_in_ms + hold_ms` мс.
- **Click-through**: оверлей не перехватывает события мыши. Кликать и работать с программами под ним — нормально.
- **Без фокуса**: окно появляется без захвата фокуса клавиатуры; активное окно не меняется.
- **Один экземпляр**: виджет создаётся лениво при первом пробуждении и далее переиспользуется. Мерцания при повторных срабатываниях нет.


## 7. Подбор оптимальных значений

### Размер шрифта

| Разрешение | Рекомендуемый `font_pt` |
|------------|-------------------------|
| FullHD (1920×1080) | 32–80 |
| 2K (2560×1440) | 48–100 |
| 4K (3840×2160) | 80–160 |

При `font_pt` выше ~120 на FullHD в `max_items = 10` влезет 1–2 строки. Уменьши
`max_items` или снизь шрифт.

### Когда увеличить `hold_ms`

- Много строк (`max_items > 8`) — добавь 500–1000 мс.
- Крупный шрифт — взгляд успевает быстрее, но на FullHD надо больше времени сканировать длинные строки.
- Медленные реакции wake-word'а (бывает при загруженном CPU) — первые 100–200 мс оверлей всё равно проявляется; `hold_ms = 2000+` компенсирует.

### Когда нужен halo (`shadow_enabled = true`)

- Всегда при `backdrop_enabled = false` — без подложки буквы могут сливаться с фоном рабочего стола.
- При светлом тексте на тёмной подложке — тёмный halo усиливает резкость края.
- При `backdrop_enabled = true` и хорошем контрасте `text_color` / `backdrop_color` — halo опционален, можно отключить для чуть более чистого вида.

### Контрастные пары

Базовое правило: `text_color` и `shadow_color` должны быть **противоположными по яркости**. Два рабочих сценария:

| Сценарий          | `text_color`  | `shadow_color` | `backdrop_color` |
|-------------------|---------------|----------------|------------------|
| Тёмный текст / светлый фон | `#1a1a1a` / `#5a0000` | `#ffffff` / `#fdf6e3` | `#fdf6e3` / `#fffbf0` |
| Светлый текст / тёмный фон | `#e8e0d0` / `#f5f0e8` | `#000000` / `#1c1c1c` | `#1c1c1c` / `#2b2b2b` |

### Палитра готовых цветов

**Тёмно-красные / бордовые (для `text_color` на светлом фоне):**
`#5a0000`, `#6b1a1a`, `#7a2020`, `#4a0000`, `#3d0c0c`

**Тёмно-серые / графитовые (для `text_color`):**
`#1a1a1a`, `#2b2b2b`, `#333333`, `#1c1c1c`, `#0d0d0d`

**Песочные / тёплые (для `backdrop_color` на светлой теме):**
`#fdf6e3`, `#fffbf0`, `#fef9e7`, `#faf3d8`, `#f5ecd7`

**Тёмные (для `backdrop_color` на тёмной теме):**
`#1c1c1c`, `#2b2b2b`, `#232323`, `#1e1e2e`, `#252525`


## 8. Известное поведение и нюансы

- **Рестарт обязателен**: параметры `[ui.wake_hint]` из `settings.toml` читаются один раз при запуске (`python main.py --ui pyside6`). После правки файла — перезапусти приложение.
- **`wake_hints.json` тоже читается один раз**: список строк собирается лениво при первом срабатывании wake-word'а в сессии. Если правишь файл — перезапусти приложение.
- **Глобальный QSS не мешает**: размер шрифта и цвет подложки задаются локальным stylesheet виджета, который имеет приоритет над application-level QSS-темой (`solarized.qss` и другими). Это намеренно.
- **Практический лимит шрифта**: при `font_pt = 320` на FullHD (1080 пикселей по высоте) влезет 1–2 строки. Учитывай это при выборе `max_items`.
- **Новые команды**: команды из реестра, отсутствующие в `wake_hints.json`, автоматически добавляются в конец списка с дефолтным синонимом — обновление приложения не «ломает» шпаргалку.
- **Удалённые команды**: команды из `wake_hints.json`, которых больше нет в реестре, молча отбрасываются с предупреждением в `logs/voice_ai.log`. Файл удалять не нужно — просто убери или исправь запись.
- **`monitor = "active_window"`**: принимается без ошибки, но ведёт себя как `"primary"`. Используй `"cursor"` на мультимониторных сетапах.


## 9. Дальнейшее развитие

- **`scripts/suggest_wake_hints.py`** (в планах): утилита будет анализировать `logs/recognized.log` и предлагать обновлённые `label`'ы на основе реально произносимых фраз — что-то вроде «ты чаще говоришь "запиши" вместо "запиши заметку", предлагаю укоротить». Запускается вручную, результат — патч к `wake_hints.json` на проверку.


## 10. Где править список команд: краткая шпаргалка

Полный формат и правила описаны в разделе 5. Здесь — TL;DR.

### Файл

- **`config/wake_hints.json`** — единственный источник правды для содержимого шпаргалки.
- Образец-стартер: **`config/wake_hints.example.json`** (в репо, безопасно копировать).
- Если `config/wake_hints.json` нет — оверлей всё равно работает: список собирается автоматически из реестра команд (по первому синониму каждой).

### Первый запуск (создать свой список)

```bash
# Windows / PowerShell — из корня проекта
copy config\wake_hints.example.json config\wake_hints.json
```

```bash
# Bash / WSL
cp config/wake_hints.example.json config/wake_hints.json
```

Затем открой `config/wake_hints.json` в любом редакторе.

### Что можно править

| Хочу… | Что менять в записи |
|---|---|
| Изменить текст строки | `"label": "новый текст"` |
| Скрыть команду из шпаргалки | `"show": false` (запись не удаляй — пригодится потом) |
| Поменять порядок | `"order": <число>` (меньше — выше; команды без `order` уходят в конец в порядке регистра) |
| Добавить новую команду в JSON | новая запись `{"command": "<имя из реестра>", "label": "...", "show": true, "order": N}` |

### Чего НЕ нужно делать

- Не меняй поле `"command"` — это стабильный идентификатор, привязанный к коду. Подбирай только `label` / `show` / `order`.
- Не правь `config/wake_hints.example.json` под себя — это репозиторный шаблон, его перезапишет следующий `git pull`. Свои правки клади в `config/wake_hints.json` (он в `.gitignore`).
- Не удаляй запись, если хочешь временно её скрыть — поставь `"show": false`. Так история твоих предпочтений сохранится.

### После правки

- Перезапусти `python main.py --ui pyside6` — список читается лениво при первом срабатывании wake-word'а в сессии и кешируется до конца сессии.
- Скажи «Шурочка» — проверь, что появился твой обновлённый список.

### Где взять имя команды (`"command"`)

Канонические имена — это поле `name` в классах команд (директория `commands/`). Текущий список:

| `command` | Что делает | Дефолтный синоним |
|---|---|---|
| `note` | Записать голосовую заметку | запиши заметку |
| `screenshot` | Сделать скриншот | сделай скриншот |
| `question` | Задать вопрос LLM | ответь на вопрос |
| `pause` | Пауза медиа | пауза |
| `resume` | Продолжить медиа | продолжи |
| `mute` | Заглушить чужие приложения | выключи звук |
| `unmute` | Снять заглушку | включи звук |
| `volume_up` | Громче | сделай громче |
| `volume_down` | Тише | сделай тише |
| `seek_forward` | Следующий трек | следующий трек |
| `seek_backward` | Предыдущий трек | предыдущий трек |
| `skip_forward` | Перемотать вперёд | перемотай вперёд |
| `skip_backward` | Перемотать назад | перемотай назад |
| `reminder` | Поставить напоминание | напомни через |
| `list_reminders` | Перечислить напоминания | перечисли напоминания |
| `stop` | Стоп / отменить | стоп |

Если в коде появится новая команда (новый класс с `name = "..."` в `commands/`) — она автоматически добавится в шпаргалку с дефолтным синонимом, без ручной правки `wake_hints.json`. Чтобы дать ей нужный `label` и место в порядке — добавь запись в JSON.
