# Голосовая подписка на канал YouTube

После перезапуска Шурочки скажите: **«Шурочка, подпишись на канал»**.
В активном окне Яндекс.Браузера должна быть открыта обычная страница ролика
YouTube. Войдите в свой аккаунт заранее. Поддерживается русский интерфейс,
светлая и тёмная темы, основной монитор.

Команда ищет штатный значок полного экрана, затем кнопку в полосе автора
под плеером. Если открыт полноэкранный плеер, она нажимает Esc, подтверждает
выход, выполняет подписку и пытается вернуть полный экран через найденную
кнопку. Воспроизведение
не переключается намеренно; подписка и колокольчик — разные действия.

Кнопка «Подписаться» нажимается только один раз. Подтверждение «Подписалась
на канал» звучит после обнаружения «Вы подписаны» на той же строке. Уже
существующая подписка сохраняется, повторный клик не выполняется. Если
кнопка не видна, команда просит открыть её под видео; прокрутка не выполняется.
Отсутствие подтверждения, например при запросе входа в аккаунт, озвучивается
отдельно. При смене окна, заголовка вкладки или размеров окна действия
прекращаются. Ошибки восстановления полного экрана записываются в лог.
PyAutoGUI failsafe (перемещение мыши в угол) прекращает дальнейшие действия.

YouTube официально поддерживает F для переключения полного экрана и Esc
для выхода: [справка о горячих клавишах](https://support.google.com/youtube/answer/7631406?hl=en).
Esc используется только после распознавания полноэкранного плеера. Для
возврата сохранён клик по кнопке: справка предупреждает о необходимости
фокуса на плеере, а после подписки фокус может остаться на кнопке автора.
Дополнительный клик по видео ради фокуса может изменить состояние паузы.
F11 управляет полноэкранным окном браузера и здесь не используется.

## Настройка фраз

Добавьте секцию в свой `config/voice_commands.toml`; существующий файл не
нужно заменять примером целиком:

```toml
[commands.subscribe_channel]
enabled = true
mode = "extend"
synonyms = ["подпиши меня на канал", "подпишись на этот канал"]
hint = "подпишись на канал"
show_in_hints = true
order = 13
```

Порядок и число видимых подсказок определяются существующими настройками.
Фраза «подписывайтесь на канал» остаётся фильтруемой галлюцинацией Whisper.

## Образцы кнопок и обслуживание

Шаблоны находятся в `assets/youtube_subscription/`, голосовые ответы —
в `assets/ack/subscribe_channel_*.wav`. Поиск учитывает масштабы образцов
80%, 100%, 125%, 150%, 175% и 200%. Это не гарантия работы при любом масштабе:
изменения шрифтов, оформления YouTube и их комбинаций с масштабом браузера
могут потребовать новых образцов.

Образцы сняты с публичной страницы без входа в аккаунт. Для состояния
«Вы подписаны» локально показан уже присутствующий штатный элемент
уведомлений; подписка на сервере не создавалась. Значки полного экрана
отрендерены из штатных SVG, поскольку недоступная трансляция скрывает
панель управления. Происхождение записано в `source.json`. Снимки в
`tests/fixtures/youtube_subscription/` проверяют распознавание интерфейса,
а не успешность подписки на сервере.

Для своего интерфейса сохраните PNG кнопок с минимальным полем вокруг
них под именами `subscribe_local.png`, `subscribed_local.png`.
Образец «Вы подписаны» можно снимать на любом уже подписанном канале.
Названия новых образцов должны начинаться с `subscribe_` / `subscribed_`.
Значки плеера сохраняются как `enter_local.png` / `exit_local.png`: белый
значок на чёрном фоне, без подсказки и соседних кнопок. Исходные образцы
можно заменить, если они устарели. Не уменьшайте пороги совпадения для
обхода ошибок: неоднозначный поиск должен завершаться без клика.

Разработчик может обновить эталонные образцы командой
`python scripts/capture_youtube_reference.py` (дополнительно нужен Playwright
и установленный Chromium; они не требуются для работы Шурочки).
Голосовые ответы пересоздаются через `python -m utils.generate_ack_phrases`.

## Проверка

```powershell
python -m pytest tests/test_subscribe_channel.py tests/test_commands_registry.py tests/test_voice_commands_config.py -q
```

Ручная приёмка: проверить обе темы в обычном и полноэкранном плеере;
повторить команду после подписки; проверить неподписанный канал без входа
в аккаунт и отсутствие видимой кнопки. Проверить возврат курсора и полного
экрана, а также прекращение действий при переключении в другое окно.
Shorts, другие браузеры, отписка, колокольчик и второй монитор не входят
в первую версию.
