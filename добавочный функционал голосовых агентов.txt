# Полный каталог функций голосовых ассистентов

Ниже — результат анализа функциональности Alexa, Google Assistant, Siri, Алисы, Маруси, Салюта, а также десктопных open-source проектов (PyGPT, Jarvis, Friday, Mycroft, Home Assistant Voice) и вашего текущего проекта Shurochka. Для каждой категории указано, что **уже есть** у вас и что можно **добавить**.

---

## 1. Управление медиа и музыкой

**Уже реализовано:** play/pause, next/prev track, volume up/down, mute/unmute (через `player_commands.py`, `media_keys.py`).

**Можно добавить:**

- Воспроизведение конкретного трека/артиста/жанра по имени — интеграция с Spotify/YouTube Music/VK API по голосовой команде «включи джаз» или «поставь Metallica»
- Поиск и запуск подкастов / аудиокниг
- Команда «что сейчас играет?» — получение метаданных текущего трека (через WinRT/MediaSession API)
- Sleep-таймер — «выключи музыку через 30 минут»
- Управление плейлистами — «добавь в избранное», «создай плейлист для работы»
- «Поставь на повтор» / «включи перемешивание»
- Управление аудиобалансом — «увеличь басы»

## 2. Таймеры, будильники, напоминания

**Уже реализовано:** ничего из этой категории.

- **Будильники** — «разбуди меня в 7 утра», повторяющиеся будильники («каждый будний день»), будильник с музыкой
- **Напоминания** — «напомни через час оплатить счёт», «напомни завтра в 15:00 позвонить маме», привязка к дате/времени с сохранением в JSON/SQLite
- **Pomodoro-таймер** — «запусти помодоро», чередование рабочих и перерывных интервалов с TTS-уведомлениями
- **Секундомер** — «запусти секундомер», «стоп», «круг»

## 3. Погода, новости, информационный брифинг

**Уже реализовано:** ничего из этой категории.

**Можно добавить:**

- **Погода** — «какая погода?», «будет ли дождь завтра?», «прогноз на выходные» (OpenWeatherMap API / wttr.in)
- **Новости** — «что нового?», краткая сводка по RSS/API новостных агентств (ТАСС, Lenta, NewsAPI)
- **Утренний/вечерний брифинг** — автоматическая сводка при запуске: погода + новости + события из календаря + напоминания. У Alexa это «Flash Briefing», у Google — «Good Morning routine»
- **Курсы валют и акций** — «какой курс доллара?», «сколько стоит биткоин?»
- **Пробки и маршруты** — «как доехать до работы?», «какие пробки?»

## 7. Веб-поиск и ответы на вопросы

**Уже реализовано:** `QuestionCommand` — вопрос направляется в LLM.

**Можно добавить:**

- **Веб-поиск** — если LLM не знает ответа, делать поисковый запрос (DuckDuckGo API, SearXNG) и подкармливать контекстом модель
- **Wikipedia** — «расскажи про чёрные дыры» — быстрый поиск по Wikipedia API с озвучкой summary
- **Поиск определений и перевод слов** — «что значит serendipity?», «как пишется accommodation?»
- **Математические вычисления** — «сколько будет 15% от 3200?», «конвертируй 5 миль в километры»
- **Конвертация единиц** — «переведи 100 фаренгейтов в цельсии»
- **RAG (Retrieval-Augmented Generation)** — подключение локальных документов (PDF, TXT, MD) как базы знаний для ответов

## 12. Память и контекст разговора

**Уже реализовано:** `SessionManager` хранит артефакты текущей сессии.

**Можно добавить:**

- **История диалогов** — сохранение всех разговоров в БД (SQLite), поиск по истории: «что я спрашивал вчера про рецепт?»
- **Долгосрочная память / профиль пользователя** — «запомни, что я люблю зелёный чай», «мой день рождения 15 марта» — ассистент использует эти факты в будущих диалогах
- **Контекст предыдущих ходов** — подача N последних реплик в prompt LLM для связного разговора (сейчас каждый turn, судя по структуре, изолирован)
- **Суммаризация длинных диалогов** — сжатие старого контекста, чтобы уместить в context window

## Приоритетная матрица для Shurochka

Если распределить по соотношению «сложность реализации / ценность для пользователя», я бы выделил три волны:

**Волна 1 — быстрые победы (1–3 дня на каждую):** таймеры и напоминания, запуск/закрытие приложений и сайтов, погода, чтение буфера обмена, контекст диалога (история ходов для LLM), шутки/факты дня, списки покупок/задач, диктовка.

**Волна 2 — средняя сложность (неделя на каждую):** веб-поиск с подачей в LLM (RAG-lite), утренний/вечерний брифинг, пользовательские макросы-рутины, перевод, работа с файлами (поиск/чтение), долгосрочная память пользователя, Telegram-интеграция.

**Волна 3 — крупные фичи (недели):** Home Assistant / IoT-интеграция, календарь Google/Outlook, vision-анализ скриншотов, полноценная плагинная система, профили пользователей с голосовой верификацией, email-интеграция.
